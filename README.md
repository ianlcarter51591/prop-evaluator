# 📊 Prop Evaluator

A sports analytics web application built with Streamlit designed to evaluate player props, cross-reference market odds, and highlight betting discrepancies across major sports leagues.

## 🚀 Features

* **Odds & Line Evaluation**: Interface for analyzing player prop markets across major sports leagues.
* **Sharp Line Comparison**: Evaluates execution odds against sharp market benchmarks to uncover value.
* **Custom Analytics Engine**: Simulates player outcomes to estimate probability edges and implied projections.

## 🛠️ Tech Stack

* **Language**: Python 3.10+
* **Framework**: Streamlit
* **Data Processing**: Pandas, NumPy
